# 택시 승객 선택과 운행 수익 최적화

세종대 2026 F AI챌린지 출품작. 대회 도로망에서 택시가 어느 승객을 태우고 언제 대기해야 하루 순수익이 높아지는지 실험한다. 공식 환경은 요금과 팁을 합산한 뒤 유류비를 차감해 운행 결과를 평가한다.

첫 번째 승객 후보를 고르는 기준 정책에서 시작해 분당 순수익에 따른 승객 선택과 대기 기준을 비교한다. 후속 실험에서는 운행이 끝나는 시각과 위치가 다음 영업 기회에 미치는 영향까지 반영한다.

## 기본 제출 파일 생성

Google Colab에서 `Taxi_Optimization.ipynb`를 열고 첫 업로드 셀에 대회 파일 `nodes.csv`, `edges.csv`, `train_requests.csv`, `test_requests.csv`를 올린다. 셀 1~7을 순서대로 실행하면 Day 1~2로 정책을 선택하고 Day 3으로 검증한 뒤 Day 4~5의 행동을 `resultset.csv`에 저장한다. 이후 셀에는 정책 개선 실험과 개별 평가 절차가 담겨 있다.
